# Image sizes (shopping)

Buy or commission larger; we can always shrink. Prefer WebP/JPEG, colour photos OK, site greyscales heroes in CSS if needed.

## Hero (home, behind transparent navbar)

| | |
|---|---|
| **Ideal** | **2400 × 1600** px (3:2) |
| Minimum | 1920 × 1080 |
| Retina-safe | 2880 × 1920 or 3840 × 2160 |
| Framed | Subject (face/scene) not tight to edges, navbar eats ~80px top; headline sits centre |
| Look | Strong B&W potential; one clear focal point; Nigeria/rural North-Central if you can source ethically |

You’ll want **1 hero** for home launch; inner pages can reuse a second quieter wide image later at the same size.

## Inner page banners (About, Programs, etc., later)

Same family: **2400 × 1200** (2:1) or reuse hero crop. Less critical than home.

## Logo (when you have one)

| | |
|---|---|
| **Best** | SVG wordmark |
| Raster fallback | PNG **800 × 200** transparent (displays ~180-220px wide) |
| Icon only | **512 × 512** PNG/SVG |

Until then the site typesets **910DF**.

## Program / cause cards (later)

**1200 × 800** (3:2) each, six programs. Consistent crop helps the grid.

## Don’t bother yet

Gallery grids, team headshots, event covers, out of v1.
