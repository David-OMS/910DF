# Programme card images

Drop files here, then set `imageSrc` in `src/content/home.ts` for that programme.

| Programme id | Filename |
|---|---|
| water | `water.jpg` |
| energy | `energy.jpg` |
| school-support | `school-support.jpg` |
| tuition | `tuition.jpg` |
| menstrual-hygiene | `menstrual-hygiene.jpg` |
| nutrition | `nutrition.jpg` |

Target size: **1200 × 800** (3:2). WebP is fine too, match the extension in `imageSrc`.

`4.2.jpg` is an unused tuition alternate, safe to delete when you no longer need it.

Example:

`imageSrc: "/images/programs/water.jpg"`
